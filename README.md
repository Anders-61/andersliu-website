# Anders Liu 个人官网

刘译桥 (Anders Liu) 的个人作品集网站。

## 在线访问

- 网站地址：https://andersliu.com
- 备用地址：https://anders-liu.vercel.app

## 技术栈

- 纯 HTML + CSS + JavaScript
- 响应式设计（移动端优先）
- 支持中英文双语切换

## 本地预览

```bash
# 直接打开 index.html 即可预览
open index.html
```

## 部署

本仓库已配置 Vercel 自动部署，推送代码后自动更新。
